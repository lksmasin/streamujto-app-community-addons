Jak nainstalovat doplněk

1
Klikněte na Kopírovat URL u vybraného doplňku
2
V aplikaci otevřete Nastavení → Doplňky úložišť
3
Klepněte na + Přidat → Zadat URL adresu
4
Vložte zkopírovanou URL a potvrďte
